Phase 1 — Fundamentals

Build strong base knowledge before you go deep into architecture or automation.

Weeks 1–8Goal: become comfortable with Linux, networking, Git, AWS core services, and hands-on account setup.
Week 1

Linux & Command Line Basics

  • File system navigation, permissions, users
  • Bash scripting fundamentals, loops, variables
  • SSH, SCP, process management
  • Package management with apt and yum
Project: Automate server setup with a bash script
Week 2

Networking Fundamentals

  • OSI model, TCP/IP, DNS, HTTP and HTTPS
  • Subnetting and CIDR notation
  • Firewalls, NAT, routing concepts
  • Tools: curl, dig, netstat, traceroute
Project: Create a visual network map and troubleshoot sample traffic flows
Week 3

Git & Version Control

  • Git basics: commit, branch, merge, rebase
  • GitHub repos, pull requests, issues, Actions basics
  • Markdown and README best practices
  • .gitignore, .env files, secrets hygiene
Project: Create a GitHub portfolio repo
Week 4

Cloud Concepts & AWS Overview

  • IaaS, PaaS, SaaS, shared responsibility
  • Public, private, and hybrid cloud models
  • AWS global infrastructure: Regions and AZs
  • AWS Console, CLI, and SDK setup
Start: AWS Cloud Practitioner prep
Week 5

AWS Compute: EC2 & Lambda

  • EC2 instance types, AMIs, key pairs
  • Security groups and Elastic IPs
  • AWS Lambda functions, triggers, events
  • Auto Scaling Groups basics
Project: Deploy a web app on EC2
Week 6

AWS Storage: S3 & EBS

  • S3 buckets, policies, versioning, lifecycle
  • EBS volumes and snapshots
  • S3 static website hosting
  • CloudFront CDN basics
Project: Host static site on S3 and prepare for CloudFront
Week 7

IAM & Security Basics

  • Users, groups, roles, permissions
  • Policies, least privilege, MFA
  • Access keys and credential hygiene
  • Basic account hardening checklist
Project: Create an AWS account security baseline
Week 8

VPC, CLI & Monitoring

  • VPCs, subnets, route tables, gateways
  • AWS CLI profiles and automation basics
  • CloudWatch metrics, logs, and alarms
  • Public and private network design
Project: Build a basic VPC and monitor an EC2 instance

Phase 2 — Core AWS + DevOps

Move from service familiarity into operating patterns, automation, and delivery workflows.

Weeks 9–16Goal: become confident with scalable architecture, Terraform, CI/CD, and architect-style thinking.
Week 9

Databases with RDS

  • Relational database basics and SQL refresh
  • RDS engine options and backups
  • Snapshots, Multi-AZ, parameter groups
  • Choosing managed databases wisely
Project: Connect a small app architecture to RDS
Week 10

Load Balancing & Auto Scaling

  • Application Load Balancer and target groups
  • Health checks and traffic flow
  • Launch templates and scaling policies
  • High availability design basics
Project: Deploy a highly available web tier
Week 11

Cloud Practitioner Review

  • Review AWS billing, support, and global services
  • Practice exams and domain-by-domain revision
  • Close weak areas from weeks 1–10
  • Book or attempt CLF-C02 exam
Milestone: Cloud Practitioner exam checkpoint
Week 12

Docker Fundamentals

  • Images, containers, Dockerfiles, registries
  • Volumes, networks, environment variables
  • Local debugging and container workflows
  • Containerizing a simple application
Project: Containerize a web app with Docker
Week 13

Terraform Basics

  • Providers, resources, variables, outputs
  • Terraform state and remote state concepts
  • Modules and reusable infrastructure
  • Plan, apply, and destroy safely
Project: Provision AWS resources with Terraform
Week 14

CI/CD with GitHub Actions

  • Workflow files, jobs, runners, secrets
  • Lint, test, build, and deploy stages
  • Artifact delivery patterns
  • Rollback and safe deployment thinking
Project: Auto-deploy static site from GitHub to S3
Week 15

Route 53 & CloudFront

  • DNS records, aliases, hosted zones
  • CloudFront distributions and cache behavior
  • TLS certificates and HTTPS delivery
  • Invalidations and edge basics
Project: Put your site behind CloudFront with HTTPS
Week 16

Solutions Architect Thinking

  • Storage, database, and compute tradeoffs
  • Resilience, fault tolerance, decoupling
  • Architecture diagrams and reasoning
  • Begin SAA-C03 structured preparation
Project: Draw and explain a reference AWS architecture

Phase 3 — Job-Ready Buildout

Turn your knowledge into portfolio-ready work, stronger architectural judgment, and interview material.

Weeks 17–26Goal: build capstone-quality projects and start applying with confidence.
Week 17

Serverless Foundations

  • Lambda execution model and permissions
  • API Gateway basics and request flow
  • DynamoDB concepts and use cases
  • Event-driven design thinking
Project: Build a simple serverless API
Week 18

Containers on AWS with ECS

  • ECR, task definitions, services
  • Fargate versus EC2 launch type
  • Networking and logs for containers
  • Scaling container workloads
Project: Deploy a Dockerized app on ECS
Week 19

Kubernetes Basics

  • Pods, deployments, replica sets
  • Services, ingress, namespaces
  • Secrets and config maps
  • kubectl debugging workflow
Project: Run and troubleshoot an app in Kubernetes
Week 20

EKS & Observability Overview

  • What EKS manages for you
  • Cluster concepts and workloads
  • Logs, metrics, and troubleshooting paths
  • When to choose EKS versus ECS
Project: Create an architecture comparison: ECS vs EKS
Week 21

Security Hardening

  • KMS, Secrets Manager, Parameter Store
  • Policy review and least privilege tuning
  • Logging, alerts, and audit thinking
  • Basic secure-by-default patterns
Project: Harden one of your existing deployments
Week 22

Backup & Disaster Recovery

  • RTO and RPO fundamentals
  • Backup strategy per service type
  • Snapshots, replication, DR patterns
  • Cross-region recovery thinking
Project: Write a DR plan for your cloud portfolio app
Week 23

Cost Optimization & FinOps Basics

  • Tagging and cost visibility
  • Right-sizing and storage choices
  • Cloud pricing review habits
  • Communicating tradeoffs to stakeholders
Project: Create a cost review sheet for your lab environment
Week 24

Capstone Architecture Design

  • Combine frontend, backend, data, and CI/CD
  • Add DNS, CDN, monitoring, and IAM
  • Define environments and deployment flow
  • Prepare recruiter-friendly architecture notes
Project: Finalize your capstone solution design
Week 25

Capstone Build & Documentation

  • Implement the architecture end to end
  • Create screenshots and GitHub documentation
  • Record lessons learned and tradeoffs
  • Prepare README and deployment guide
Project: Ship the capstone publicly
Week 26

CV, Applications & Interview Prep

  • Update CV, LinkedIn, and GitHub profile
  • Practice architecture and troubleshooting answers
  • Prepare STAR stories from your projects
  • Start consistent applications and outreach
Milestone: Apply for cloud support, junior cloud, or cloud engineer roles
